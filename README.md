# 欧盟标签打印网页版

在线地址：

https://qazwsxzhaozhe.github.io/eu-label-printer/

这是一个纯静态网页，不需要后端、数据库或安装程序。

## 使用

1. 用 Chrome 或 Edge 打开在线地址。
2. 在 Model Number 输入框中输入或扫描型号。
3. 设置标签数量，点击“打印标签”。
4. 打印时选择 100 × 100 mm 标签纸、无边距、100% 缩放。

## 说明

- 原始标签画面为 100 × 150 mm，网页会等比缩放并居中到 100 × 100 mm 页面，完整保留所有内容。
- 每台电脑需要安装对应的标签打印机驱动。
- Model Number 只在浏览器本地处理，不会上传到服务器。
