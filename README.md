# 欧盟标签打印网页版

在线地址：

https://qazwsxzhaozhe.github.io/eu-label-printer/

这是一个纯静态网页，不需要后端、数据库或安装程序。

## 使用

1. 用 Chrome 或 Edge 打开在线地址。
2. 在 Model Number 输入框中输入或扫描型号。
3. 设置标签数量，点击“打印标签”。
4. 打印时选择 100 × 150 mm 标签纸、无边距、100% 缩放。

## 首次打印校准

1. 点击“打印 100 × 150 校准页”。
2. 打印后量一下左上角黑色方框外沿，应为 10 × 10 mm。
3. 如果标签内容只占纸张上半段，说明 Chrome 或打印机驱动仍按 100 × 100 mm 输出。请重新选择 100 × 150 mm 纸张并关闭“适应页面”，然后再次打印校准页。

## 说明

- 标签按 100 × 150 mm 原始比例直接打印。
- 每台电脑需要安装对应的标签打印机驱动。
- Model Number 只在浏览器本地处理，不会上传到服务器。
